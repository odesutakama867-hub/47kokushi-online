# 47国志 ONLINE 開発版 v0.3

## 起動方法
1. ZIPを展開する。
2. `index.html` をChrome、Edge、Safariなどで開く。
3. プレイヤー名と開始都道府県を選び「ゲーム開始」。

## v0.3で動く機能
- 47都道府県を選択して開始
- 各都道府県にCPU勢力を配置
- 資金・兵糧・兵力・士気・城規模
- 商業、開墾、徴兵、築城、士気向上
- 月送りとCPUの簡易内政
- 隣接地への試作合戦、CPUからの攻撃
- ブラウザ内へのセーブ（localStorage）

## まだ実装していないもの
- 1,754市町村単位の正確な領地データと地図
- 元ゲームの全ルール、イベント、人材、知事選、外交、交易など
- 元ゲームと同一のバランス・AI
- オンライン同期、ルーム機能との統合
- 実地形に沿った地図表示

これは独自に作った初期プロトタイプです。元ゲームのプログラムや素材をコピーしていません。現在の地図表示は47都道府県の選択グリッドで、地理的な配置図ではありません。
オンライン機能は未接続です。複数PCから同じセーブデータを共有することはできません。
